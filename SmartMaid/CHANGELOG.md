# 更新日志

SmartMaid 的版本变更记录，版本号遵循语义化版本（`主版本.次版本.修订号`）。

---

## 0.1.2 — 2026-10-01

### 新增：任务队列

女仆现在会**排队干活**，而不是做一件忘一件。

- **双队列** —— 分「长期任务」与「短期任务」两条队列，短期做完了才接着做长期。
- **优先级** —— 你亲口下的指令**插到队首**（正在做的事暂停让位，不丢弃），桌宠自动识别的指令**排到队尾**。
- **打断不丢活** —— 战斗、坐下、被叫停时任务只是**暂停**，忙完自动接着做，不会从头再来。
- **进度接续** —— 挖矿 / 耕作 / 建造 / 烧炼 / 采集被打断后，能从中断处继续。
- **退出也不丢** —— 队列存进存档，重新召唤女仆后**自动接着做**。
- **不重复下发** —— 同一件事不会排两遍；不同的事（比如烧铁矿和烧金矿）可以同时排。
- **熔炉不打架** —— 烧炼自动找**空闲熔炉**，一座熔炉同一时间只烧一种矿。
- 新增**存取箱子**任务。

### 新增：游戏内菜单

`Shift + 右键` 女仆打开全新的两级菜单，不再是一列设置项。

- 绿色系配色 + 世界半透明遮罩，面板与卡片分层。
- 左侧 **3D 女仆预览**，下方**装备概览**（4 件盔甲 + 主手 + 副手）。
- **生命 / 饥饿状态条**实时刷新（原版红心 + 鸡腿贴图）。
- **任务页** —— 添加任务（数字参数可加减微调）、删除、上移、整组停止、一键清空；
  涉及坐标的任务可选 **准星指向** 或 **女仆脚下**。
- **设置页** 8 项，点一下即改。
- 底部动作按钮：**跟随我 / 坐下待命 / 召回 / 停止当前**，每次操作都有回执提示。
- 背包入口直接跳转原有背包界面（**背包本身没有任何改动**）。

### 改进

- 桌宠指令带优先级与分组：一批展开的多个任务在菜单里**折叠成一组**，可以整组停止。

### 已知限制

- **脚本任务（script）不支持跨重新召唤接续** —— 游戏内被打断仍可继续，但退出游戏后重新召唤会从头执行。
- 菜单坐标暂只支持**准星指向**与**女仆脚下**；"主人脚下"待后续版本。
- 战斗系统**未纳入队列**（始终保持最高优先级，只在菜单顶部显示状态）。

## 0.1.1 — 2026-09-29

### 新增

- **整合包兼容** —— 破坏与放置由主人的虚拟玩家身份执行，能正确触发原版与第三方模组的方块事件。
- **数据包标签可覆盖** —— 搭路建材 `#smartmaid:bridge_blocks`、战斗排除 `#smartmaid:never_target`、
  合成白名单 `#smartmaid:craftable`、丢弃物 `#smartmaid:junk`。
- 女仆数据按存档隔离，存放在 `<存档>/smartmaid/maids/`，旧文件自动迁移。
- 调试日志改为配置文件控制（`config/smartmaid/main.json`），运行期生效，默认关闭。

### 改进

- **采集判据修正** —— 连通性按资源本身判断（深色橡木也算"树"），选定目标后整棵采完。
- **起点容错** —— 目标被前置任务挖掉时，在附近半径 2 格内寻找同类资源。
- 不可达目标不再死磕，自动放弃并交给上层重试或跳过。
- **背包满自动整理** —— 合并同类堆叠 + 丢弃垃圾（丢在身后一格），无垃圾可丢时会上报。

### 安全 / 其他

- 命令权限按运行环境自动降级：单人世界开作弊即可用，专用服务器仅管理员可用。
- 桌宠联动默认关闭，专用服务器启动时跳过。
- 模组图标更新。

## 0.1.0 — 2026-09-24

首个公开版本。

- 规则引擎驱动的 AI 女仆：**跟随 / 战斗 / 跳跃寻路 / 挖矿建造 / 原子指令协议**。
  - 战斗：近战走位、远程边退边射、盾牌格挡、半血自动进食回血。
  - 寻路：可跨 1~3 格沟、上 1 格高台；寻路失败时自动降级为直线移动并挖方块 / 搭方块通过。
- `/summonmaid` 召唤，每名玩家仅限一只；退出游戏自动消失并本地保存装备。
- `/maidtasks` 指挥干活：挖矿 / 耕作 / 建造 / 收集 / 合成 / 烧炼。
- 背包布局与玩家完全一致（41 格），界面左上角实时渲染女仆模型。
- `/maidai` 统一 JSON 指令协议（24 条指令）；`/maidanim` 表情动作；`/maidperception` 感知快照。
- 可与桌面宠物 **DeskPet** 联动（AI 对话 / 语音朗读 / 气泡）。
