## 二、Mod介绍（整段替换）

```text
概述

一个真的会替你干活的女仆。

智能女仆（Smart Maid）是一个 Minecraft 26.2 / Fabric 模组。用 /summonmaid 召唤一只只属于你的女仆（每名玩家限一只，无需驯服）。她不是跟宠——遇敌会举盾拉弓，派活会自己找路、挖开挡路的方块、把东西背回来。配合同作者的开源桌宠 DeskPet 还能聊天，但不装也完全能玩。

她会自己打架

不需要你下任何指令：

· 箭飞来之前就把盾举起来——她省掉了原版那 0.25 秒的架盾前摇，贴脸的箭也挡得住
· 近战不退，血少会绕、会边退边射
· 掉到半血以下，自己掏东西吃
· 只打敌人：她的近战和箭永远不会伤到你

她会替你干活

/maidtasks 一句话派活：挖矿、砍树、耕作、建造、合成、烧炼、存取箱子。

· 说挖矿，她自己找矿：石头挡住就先挖石头，矿埋在下面就一层层往下挖，矿挂在高处就垫方块爬上去
· 说砍树，她认的是"树"而不是"树种"——深色橡木、白桦、橡木一视同仁，选中一棵就整棵砍完，不会砍着砍着跑偏去砍整片林子
· 走不通的路，她会自己挖开、搭桥过去，不会卡在墙角发呆

干活有记性（0.1.2 新增）

· 排队干——一次派一堆活，她按顺序一件件做完
· 你优先——你临时喊一句，她把手头的先放下，做完你的再回去接着干
· 打断不丢——被怪打断、坐下休息、被叫停，她都记着，忙完回原位继续，不用从头再来
· 退出也不丢——她不是常驻实体，退出游戏会消失、装备自动存着；第二天重新召唤，人回来、装备回来、活也接着干

她会长嘴（可选）

配合同作者的开源桌宠 DeskPet：聊天栏打字或按住 Y 说话，回复冒在她头顶，还能语音朗读。

不装桌宠也完全能玩——上面的功能一个都不少。

女仆菜单

Shift + 右击打开。左边是她自己的 3D 立绘和身上穿的装备，右边是任务、背包、对话、设置、动作五个入口，下面是血条、饱食度和四个按钮：跟我走、坐下、回来、停下。

环境

Minecraft 26.2 · Fabric Loader 0.18.4+ · Fabric API 0.158.0+26.2 · Java 25。前置只有 Fabric API。代码 MIT 开源，免费、不收费。

目前还不能（如实说明）

· 脚本任务（script）暂不支持跨重新召唤接续——游戏内被打断仍会继续
· 菜单里选坐标目前只支持"准星所指"和"她脚下"两种
```

> **写作取向**：先回答"玩起来爽在哪"，再列功能。全篇不用"规则引擎""原子协议""S2C"这类词——
> 百科的读者是来找模组的玩家，不是来看架构的。技术词只保留"Fabric""MIT"这种他必须知道的。
> 每一条都对应真实实现，没有一处夸大。

## 三、版本日志（可选，用于「新建日志」）

```text
0.1.2

新增：女仆会排队干活
- 一次派一堆活，她按顺序做完
- 你临时喊一句，她把手头的先放下；做完你的再回去接着干
- 被怪打断、坐下、被叫停都不丢进度，忙完回原位继续
- 挖矿 / 耕作 / 建造 / 烧炼 / 采集能从中断处接着做
- 队列存进存档，退出游戏重新召唤后继续干

新增：女仆菜单（Shift + 右击）
- 两级菜单：3D 立绘、装备一览、血条与饱食度
- 任务页：添加 / 删除 / 上移 / 整组停止 / 一键清空，参数可加减调节，坐标可选准星或她脚下
- 设置页 8 项；背包入口跳转原有背包界面

改进
- 桌宠指令带优先级与分组，一批任务可整组显示与停止

已知限制
- 脚本任务不支持跨重新召唤接续
- 菜单坐标暂只支持准星 / 她脚下
- 战斗不参与排队（始终保持最高优先级）
```
