## 二、Mod介绍（整段替换）

> 排版提示：`概述 / 如何开始 / …` 这些小标题，如果编辑器支持标题格式就设成标题
> （mcmod 会据此自动生成右侧目录，效果见参考页面）；不支持就用**加粗整行**。

```text
概述

一个真的会替你干活的女仆。

智能女仆（Smart Maid）是一个 Minecraft 26.2 / Fabric 模组。用 /summonmaid 召唤一只只属于你的女仆（每名玩家限一只，无需驯服）。

她不是跟宠——遇敌会举盾拉弓，派活会自己找路、挖开挡路的方块、把东西背回来。配合同作者的开源桌宠 DeskPet 还能聊天，但不装桌宠也完全能玩。

如何开始

· 装好 Fabric Loader 0.18.4+ 与 Fabric API 0.158.0+26.2，把 smartmaid-0.1.2.jar 放进 .minecraft/mods/
· 进游戏执行 /summonmaid —— 女仆会出现在你脚下
· 空手右键她：坐下 / 站起；Shift + 右击：打开女仆菜单
· 想看她干活，先试试 /maidtasks mine

退出游戏女仆会消失、装备自动保存；下次 /summonmaid，人回来、装备也回来。

她会自己打架

不需要你下任何指令：

· 箭飞来之前就把盾举起来——她省掉了原版那 0.25 秒的架盾前摇，贴脸的箭也挡得住
· 近战不退，血少会绕、会边退边射
· 掉到半血以下，自己掏东西吃
· 只打敌人：她的近战和箭永远不会伤到你

她会替你干活

一条 /maidtasks 就能派活。

· 挖矿：石头挡住就先挖石头，矿埋在下面就一层层往下挖，矿挂在高处就垫方块爬上去
· 砍树：她认的是"树"而不是"树种"——深色橡木、白桦、橡木一视同仁，选中一棵就整棵砍完，不会砍着砍着跑偏去砍整片林子
· 走不通的路，她会自己挖开、搭桥过去，不会卡在墙角发呆
· 还有：耕作、建造、合成、烧炼、收集、存取箱子

干活有记性（0.1.2 新增）

· 排队干——一次派一堆活，她按顺序一件件做完
· 你优先——你临时喊一句，她把手头的先放下，做完你的再回去接着干
· 打断不丢——被怪打断、坐下休息、被叫停，她都记着，忙完回原位继续，不用从头再来
· 退出也不丢——队列存进存档，第二天重新召唤，她接着干

女仆菜单（Shift + 右击）

左边是她自己的 3D 立绘和身上穿的装备，右边是任务、背包、对话、设置、动作五个入口，下面是血条、饱食度和四个按钮：跟我走、坐下、回来、停下。

任务页支持添加 / 删除 / 上移 / 整组停止 / 一键清空；参数能加减微调，涉及坐标的可以选"准星所指"或"她脚下"。设置页 8 项，点一下即改。

她会长嘴（可选）

配合同作者的开源桌宠 DeskPet：聊天栏输入 /maidchat 进入对话模式，或按住 Y 说话——回复会冒在她头顶，还有语音朗读。

不装桌宠也完全能玩，上面的功能一个都不少。

常用指令

· /summonmaid —— 召唤女仆（每名玩家限一只）
· /maidtasks <任务> [参数] —— 派活，见下
· /maidai {json} —— 用 JSON 下发指令（桌宠走这条通道），一条脚本可串多步
· /maidanim <动作> —— 播放表情动作（挥手、鼓掌、后空翻等 11 种）
· /maidperception —— 打印一份感知快照（调试用）
· /maidchat —— 进入 / 退出聊天栏对话模式（需桌宠）

/maidtasks 任务一览

· 战斗：attack [范围] [目标] / guard [范围] / feed（喂主人）
· 生存：eat [物品]
· 采集：mine [坐标] [范围] [数量] / farm <坐标> [范围] / collect [范围]
· 建造：build <坐标> <高度>
· 生产：craft <物品> [数量] / smelt <物品> [数量]
· 搬运：transfer <从槽位> <到槽位> [数量] / chestopen <坐标> / chestput [数量] / chesttake [槽位] [数量]
· 基础：move <坐标> / look <坐标> / break <坐标> / place <坐标> / use <坐标>
· 装备：equip <物品> / store（收起）/ drop [数量] / pickup（拾取）
· 状态：sit（坐下 / 站起）/ stop / cancel / status

坐标大多可以省略——比如 mine 不给坐标，她会自动探测周围的矿物。参数也支持 ~ 相对坐标。

注意事项

运行环境：客户端与服务端都需安装。前置只有 Fabric API —— Player Animation Library 已内置在 jar 里，不用另外下载。

专用服务器权限：/summonmaid 等指令默认需要管理员权限（等同原版等级 2）；单人存档开着作弊就能用。

整合包：破坏与放置以主人的身份执行，领地保护能正常拦住女仆；搭路只消耗白名单建材，贵重方块不会被当成砖头用掉。

目前还不能（如实说明）

· 脚本任务（script）暂不支持跨重新召唤接续——游戏内被打断仍会继续
· 菜单里选坐标只支持"准星所指"和"她脚下"两种
· 战斗不参与排队——她的保命优先级永远最高
```
