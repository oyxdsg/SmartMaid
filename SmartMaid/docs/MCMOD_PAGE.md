## 二、Mod介绍（整段替换）

```text
概述

智能女仆（Smart Maid）是一个 26.2 Fabric 的开源 AI 女仆模组。行为由本地规则引擎主导（安全 / 移动 / 战斗，毫秒级响应），AI 作兜底增强；可与同一作者的开源桌宠程序 DeskPet 联动，把 AI 对话 / 语音 / 气泡接入女仆。

玩法

可通过 /summonmaid 召唤一只只属于你的女仆，每名玩家仅限一只、无需驯服；退出游戏自动消失并本地保存装备（每 5 秒持久化）；

行为由本地规则引擎驱动（毫秒级响应）：盾牌格挡、近战走位、远程弓箭边退边射、半血自动进食回血；跳跃寻路可跨 1~3 格沟、上 1 格高台，寻路失败时自动降级为直线移动并挖方块/搭方块通过；

/maidtasks 指挥她干活：挖矿（自动探测周围矿物）、耕作、建造、收集、合成、烧炼、存取箱子；

背包布局与玩家完全一致（41 格），界面左上角实时渲染女仆模型。

女仆菜单

Shift + 右击打开女仆菜单（两级）：一级菜单左侧是 3D 女仆预览与装备概览，下方为生命 / 饱食状态条，右侧是任务、背包、对话、设置、动作五个入口；底部为「跟随我 / 坐下待命 / 召回 / 停止当前」四个高频动作。

设置页可调交互距离、护卫模式、生命与回血速度、死亡掉落等，按玩家绑定保存、改完即时生效。

任务队列

女仆不再"做一件忘一件"——任务会进入队列按序执行：

长期任务与短期任务两条独立队列，短期清空后才执行长期；

主人实时下达的指令插到队首（当前任务暂停让位、不丢弃），桌宠自动识别的指令追加队尾；

战斗、坐下、被抢占时任务只是暂停，忙完自动接着做；

挖矿、耕作、建造、烧炼、采集被打断后能从中断处继续；

同一件事不会重复下发，不同的事（例如烧铁矿与烧金矿）可以同时排；

烧炼自动占用空闲熔炉，一座熔炉同一时间只烧一种矿；

队列存进存档，退出游戏后重新召唤女仆会自动继续。

聊天与语音

聊天栏对话与语音朗读为可选功能，需配合同一作者的开源桌宠程序 DeskPet（不装也完全可玩）。
```

## 三、版本日志（可选，用于「新建日志」）

```text
0.1.2

新增：任务队列
- 长期 / 短期双队列；主人指令插队首、桌宠指令排队尾
- 打断只暂停不丢弃，战斗 / 坐下后自动接着做
- 挖矿 / 耕作 / 建造 / 烧炼 / 采集支持从中断处继续
- 同一件事不重复下发；不同的事可同时排
- 烧炼自动占用空闲熔炉（一炉一矿）
- 队列存进存档，重新召唤女仆后自动继续

新增：女仆菜单（Shift + 右击）
- 两级菜单：3D 预览、装备概览、生命 / 饱食状态条
- 任务页：添加 / 删除 / 上移 / 整组停止 / 一键清空，参数可加减调节，坐标可选准星或女仆脚下
- 设置页 8 项；背包入口跳转原有背包界面

改进
- 桌宠指令带优先级与分组，一批任务可整组显示与停止

已知限制
- 脚本任务不支持跨重新召唤接续
- 菜单坐标暂只支持准星 / 女仆脚下
- 战斗系统不纳入队列（始终保持最高优先级）
```
